# Resumen Hito 1 - DocExplore

En el Hito 1 se trabajó una primera aproximación al problema general del proyecto, que consiste en buscar queries visuales dentro de documentos históricos. El objetivo final es determinar en qué página aparece una query y, en etapas futuras, aproximar también su ubicación dentro de la página. En esta entrega todavía no se implementó retrieval completo ni localización espacial; el foco estuvo en validar una base experimental de clasificación binaria.

Para ello se revisaron los datasets disponibles en el repositorio. `DocExplore_images` contiene las páginas completas del corpus y se verificaron 1500 páginas válidas. `DocExplore_queries_web` contiene recortes organizados por clase y se detectaron 35 clases válidas. Según la inspección inicial, las clases más grandes fueron `marqeur` (409), `simple_sep` (160), `S` (147), `losange` (117), `croix` (92) y `double_sep` (87). A partir de esto se eligieron `marqeur` y `simple_sep` para el experimento inicial, por ser las clases con más ejemplos y porque permiten una comparación binaria clara.

Como avances concretos, se estructuró el repositorio, se incorporó el dataset en la organización esperada, se implementaron scripts modulares para inspección, carga de imágenes, preprocesamiento, extracción de embeddings, entrenamiento y evaluación, y se generó un notebook reproducible con métricas y figuras.

Se compararon dos enfoques con train/test split estratificado: `baseline_pixels`, que usa imágenes RGB redimensionadas a 64x64, flatten, `StandardScaler` y Regresión Logística, y `clip_logreg`, que usa embeddings de `openai/clip-vit-base-patch32` más Regresión Logística. En ambos casos los resultados fueron iguales: accuracy = 1.0, precision = 1.0, recall = 1.0 y f1 = 1.0. Las matrices de confusión no mostraron errores, con 82 ejemplos de `marqeur` y 32 de `simple_sep` correctamente clasificados en el conjunto de prueba.

El análisis por threshold mostró que ambos modelos funcionan perfectamente en torno a threshold 0.5, aunque el baseline quedó más estable en un rango más amplio y CLIP fue más sensible al mover el umbral. En cualquier caso, este resultado debe interpretarse con cautela: probablemente se explica porque las dos clases elegidas son visualmente muy distinguibles y porque el experimento todavía trabaja con recortes ya separados. Por eso, aunque el hito deja una base sólida, el problema completo del proyecto sigue abierto para las próximas etapas.
